# Background Music Directory

You can place your personal background audio file here.

### How to use:
1. Place any `.mp3`, `.wav`, or `.ogg` audio file in this directory.
2. Name it `farewell.mp3` (or configure a custom filename in `config.py`).
3. When you run the app, a gentle background music controller will automatically appear at the top of the letter.

*Note: For privacy and copyright reasons, no external audio is pre-packaged. You have full freedom to add whatever instrumental, piano, or ambient track you prefer.*
